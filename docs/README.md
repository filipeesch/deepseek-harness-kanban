# Documentation Index

This directory holds the maintained documentation. Every document below owns one subject; [AGENTS.md](AGENTS.md) states where a new fact belongs and how to add, move, or delete a document. Behavior contracts live in `openspec/specs/`.

Start with the [README](../README.md) if you are installing the plugin.
